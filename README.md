# Altrua
Sitio estático de presentación y validación conceptual.

## Rutas
- `/`: página institucional del proyecto
- `/descubre/`: mensaje de educación y propósito
- `/oportunidades/`: mensaje de recompensas y grandes metas

## Estado
La encuesta funciona como prototipo local: **no guarda respuestas**. El formulario de lista de espera está deshabilitado. No enviar tráfico pagado para recopilar datos hasta conectar un backend, políticas de privacidad, consentimiento y medición.

## Despliegue
Sitio HTML/CSS/JS estático, apto para Vercel. Los recursos compartidos usan rutas absolutas (`/style.css`, `/app.js`).
